# Free ebooks and guides

Place approved public PDF downloads in this folder, using filenames with letters, numbers, hyphens or underscores and a lowercase `.pdf` extension.

Add each PDF to the `items` array in `resources.json`:

```json
{
  "title": "Your approved guide title",
  "category": "Free guide",
  "description": "A short description of the approved PDF.",
  "file": "downloads/your-approved-guide.pdf"
}
```

Publish the PDF and manifest together. The Resources page automatically shows a download card for each entry. Keep `items` empty until real files are ready. No public upload control is required: maintain downloads through the existing website publishing process. Only include material cleared for free public distribution. This folder contains no downloadable ebook yet.
